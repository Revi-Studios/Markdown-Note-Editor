# Markdown Notes

This project is/was supposed to be a minimal, leight weight and easy to use note taking web app inspired by [Obsidians](https://obsidian.md/) realtime one editor markdown editor.

## How does it work?:

> [!Tip]
> There is a hosted [released version](https://revi-studios.github.io/Markdown-Note-Editor/)

**Features:**

> [!Note]
> These features are maybe coming in the future.

- Formats _current line_ on every input
- Formats to _markdown mix_

- When hovering over a formatted text, the _formatting symbols_ are shown

- Pressing on formatted checkmarks _checks_ them in text

- Copy as _normal text_
